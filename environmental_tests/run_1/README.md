# run_1 -- circular EMRI population, Cutler-Vallisneri bias with an environmental flux deviation

PBS job 619005, finished 2026-09-16 15:24 UTC, 55584 s (15 h 26 m) wall.

## What was run

23 circular sources (e0 = 0, xI0 = 1), each at SNR = 200, A and E channels only,
band [1e-5, 0.1] Hz, dt = 10 s.  Each source is fitted twice:

* `0PA`    -- 8 vacuum parameters: m1, m2, a, p0, e0, qS, phiS, Phi_phi0
* `0PA+PN` -- the same 8 plus C_p, the deviation amplitude

The injection carries a multiplicative environmental term on the flux,
`env = 1 + A_PM (p/10)^n_PM`, with `n_PM = 8` and `A_PM = 1.92e-5 (m1/1e6)`.

## Headline result

19 / 23 converged; 4 failed (idx 8, 13, 14, 16).  The split is clean in p0:
converged span 4.85-7.40, failed span 7.76-11.75, no overlap.  `PN >= 0PA` on
overlap holds for all 23.

On the 19 converged sources the systematic bias never exceeds **0.82 sigma**
(worst case Phi_phi0 on idx 15); the median is 0.03 sigma.

Extending the model to `0PA+PN` does **not** remove the bias.  The absolute bias
is unchanged (median ratio ~1.00 on m1, m2, a, p0); the ~10x drop in b/sigma comes
almost entirely from sigma inflating 5-22x, driven by |corr(A_PM, theta)| ~ 0.89-0.91
on those parameters.  Only the angles improve honestly (~5-10% less bias, ~1.1x sigma).

The bias is controlled by p0, not by mass ratio: `b/sigma = K (p0/10)^8` with
K = 9.33 [7.03, 11.80].  Over the sampled range eta varies 2.74x and contributes
little, because at fixed SNR the dephasing and the phase precision scale together.
Extrapolating, 2-10 sigma lands at p0 ~ 8.3-10.1 -- which is exactly the band where
the optimiser fails, so nothing in this run confirms it.

## Caveats

* `dt = 10` aliasing is an accepted fidelity caveat (A/E shift up to 8.4% vs dt = 5,
  and dt = 5 is itself not a converged floor for several sources).
* `e0 = 0` sits on its own boundary, so sigma(e0) is unstable (2e-10 to 0.53 across
  the population) and b/sigma is meaningless there; the absolute bias is <= 4e-4.
  It is excluded from the bias tables and from panel (b) of the plot.
* The four non-converged sources' bias columns describe whichever wrong basin LM
  stopped in.  They are reported, not dropped, but they are not biases.
* The run depends on an uncommitted patch to `flux.py` on branch `environ_shubham`,
  so it is not reproducible from a clean checkout as things stand.
